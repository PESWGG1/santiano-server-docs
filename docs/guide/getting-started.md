# 新手入门

欢迎加入 **Santiano（海境）** 服务器！本页从零开始带你进入游戏。

| 项目 | 内容 |

| 服务器地址 | 待补充：例如 mc.santiano.top |
| 游戏版本 | 待补充：例如 Java 1.21.x |
| 正版验证 | 待补充：是 / 否 |
| 交流群 | 待补充：QQ / KOOK / Discord 群号 |

## 二、准备工作

1. 安装 Minecraft Java 版，并确保版本与服务器一致。
2. 使用正版启动器，或服务器指定的第三方启动器。
3. 确认网络可以连接服务器。

## 三、进入服务器

1. 打开 Minecraft，点击「多人游戏」。
2. 点击「添加服务器」，名称随意填写（例如 Santiano）。
3. 服务器地址填上面的「服务器地址」。
4. 双击进入，首次进入如需下载资源包，请耐心等待。

## 四、进入后先做什么

- 阅读「指令手册」了解基本操作。
- 完成新手任务或领取新手礼包（待补充）。
- 遵守服务器规则，友善游玩。
