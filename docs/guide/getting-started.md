# 新手入门

欢迎加入 **Santiano（海境）** 服务器！本页从零开始带你进入游戏。

## 一、服务器信息

| 项目 | 内容 |
| --- | --- |
| 服务器名称 | Santiano |
| 官网 | [santiano.top](https://santiano.top/) |
| 游戏版本 | Minecraft Java 版 26.2 |
| 正版验证 | 不需要正版账号 |
| 客户端要求 | 纯原版客户端即可进入，无需安装模组 |
| 入服方式 | 审核制，审核通过后提供服务器地址 |
| 审核 QQ 群 | 1070493995 |

## 二、申请入服

Santiano 采用审核制，服务器地址不公开。请加入审核 QQ 群 **1070493995**，按照群内要求完成审核。审核通过后，管理员会提供服务器地址和入服说明。

服主与管理员都在审核群内。入服申请、问题反馈和处罚申诉均在群内处理。

## 三、准备工作

1. 安装 Minecraft Java 版 26.2。
2. 使用能够启动该版本的启动器，不要求正版账号。
3. 使用纯原版客户端即可，无需预装模组。
4. 加入审核 QQ 群并完成审核。

## 四、进入服务器

1. 打开 Minecraft，点击「多人游戏」。
2. 点击「添加服务器」，名称随意填写（例如 Santiano）。
3. 填写管理员在审核通过后提供的服务器地址。
4. 双击服务器进入游戏。

## 五、玩法简介

Santiano 是一个最多同时在线 20 人的公益小型社区服，核心内容包括：

- 海洋主题生存；
- 玩家成长与怪物成长；
- 全服合作建设；
- 剧情与全服大事件；
- 长期养成与共同发展。

服务器通过数据包和插件扩充海洋、怪物、武器、钓鱼、商店、附魔、结构，以及下界和末地内容。客户端仍可使用纯原版，无需安装这些内容。

你可以自由选择自己的方向，各路线互不冲突：

| 路线 | 适合的玩家 |
| --- | --- |
| 建筑师 | 喜欢规划聚落、建设设施与美化世界 |
| 复兴者 | 喜欢参与公共建设、恢复与发展文明 |
| 拓荒者 | 喜欢探索、收集资源与开辟新区域 |
| 自由者 | 不固定路线，按照自己的节奏生活 |

Santiano 是合作服务器，不允许 PVP、偷窃和破坏他人成果。地图不会定期重置，玩家的长期建设会被保留。

死亡时物品会掉落并生成墓碑。墓碑保留时限为 **1 小时**，请及时返回取回物品。

## 六、进入后先做什么

- 阅读「指令手册」了解基本操作。
- 阅读「服务器规则」和审核群公告。
- 为非正版账号设置一个独立密码，不要与 QQ、邮箱或其他网站共用。
- 遵守服务器规则，友善游玩。

## 七、更多帮助

遇到登录失败、卡顿等问题，请先查看「常见问题」。仍未解决时，可在审核 QQ 群联系管理员，并提供截图和问题描述。
