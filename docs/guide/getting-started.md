## 进入服务器

1. 打开 Minecraft，点击「多人游戏」。
2. 点击「添加服务器」，名称随意填写（例如 Santiano）。
3. 填写服务器地址。
4. 双击服务器进入游戏。

## 关于服务器

Santiano 是一个最多同时在线 20 人的小型公益服。

核心玩法：

- 海洋主题生存；
- 玩家成长与怪物成长；
- 全服合作建设；
- 剧情与全服大事件；
- 长期养成与共同发展。

服务器通过数据包和插件扩充游戏内容。客户端仍可使用纯原版，无需安装这些内容。每次进入服务器会自动加载服务器所需数据包。

你可以自由选择自己的方向，这只会影响你的头衔，各路线互不冲突：

- **筑城者**：在创造服设计全服复兴建筑；
- **复兴者**：投入材料推进公共工程；
- **拓荒者**：与伙伴建立公会，拥有独立主城、故事和建筑增益；
- **自由人**：不固定路线，按照自己的节奏生活。

Santiano 是合作服务器，不允许 PVP、偷窃和破坏他人成果。地图不会定期重置，玩家的长期建设会被保留。死亡时物品会掉落并生成墓碑，墓碑保留时限为 **1 小时**。

## 进入后先做什么

- 阅读「百科残本」了解基本操作。
- 阅读所有群公告。
- 为非正版账号设置一个独立密码。
- 遵守服务器规则，友善游玩。

遇到登录失败、卡顿等问题，请先查看「常见问题」。仍未解决时，可在审核 QQ 群联系管理员，并提供截图和问题描述。
