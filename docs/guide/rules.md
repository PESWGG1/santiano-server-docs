# 服务器规则

Santiano 是以合作、长期建设和小型社区为核心的公益服务器。以下规则用于保护玩家成果与服务器运行。

## 合作与财产

- 禁止 PVP，除非管理员为特定活动临时开放并明确说明规则。
- 禁止偷窃、欺骗或擅自取用他人物品。
- 禁止破坏、改造或占用他人的建筑与设施。
- 公共工程应尊重已有规划；不确定时先在群内沟通。

## 客户端与辅助模组

服务器推荐使用纯原版客户端。允许不影响公平性的便利功能，但须遵守以下限制：

- 小地图不得开启生物雷达和洞穴模式。
- 投影模组只允许用于自己原创的建筑设计。
- 禁止投影打印机、灵魂出窍等明显提供不公平优势的功能。
- 禁止其他过于强大、可绕过正常探索或操作过程的模组与工具。

无法判断某项功能是否允许时，请在使用前询问管理员。

## 红石、刷怪塔与挂机

- 红石机器应建在初生点正负 1000 格范围之外。
- 不允许建设大型或持续造成明显服务器负载的红石机器。
- TNT 复制等部分高风险特性已被关闭，不得尝试绕过限制。
- 可以建设刷怪塔或挂机，但不得导致服务器卡顿或影响其他玩家。
- 管理员发现设施造成性能问题时，会要求所有者停用、缩小或拆除。

## 死亡与墓碑

- 死亡会掉落物品，并在死亡地点生成墓碑。
- 墓碑保留时间为 1 小时，请及时取回。
- 不得开启、破坏或恶意阻碍他人取回墓碑。

## 世界与长期建设

- 地图不会定期重置，请珍惜世界与公共环境。
- 不要在公共区域留下大面积未完成工程、浮空方块或无意义破坏。
- 大型工程、公共设施和可能影响他人的项目，建议先在群内沟通。

## 处理与申诉

违反规则时，管理员会根据影响程度采取提醒、要求整改、临时限制或移出服务器等措施。需要举报问题或对处理结果提出申诉时，请在审核 QQ 群 **1070493995** 联系管理员，并提供截图、时间、地点和相关说明。

> 群公告可能对具体活动或新功能增加临时规则，请以最新公告为准。
