# 海境漫游

你是来自遥远国度的冒险者，慕名前来探索圣地亚诺——被称为“历史漩涡”的未知海域，途中经历风暴失去了记忆，醒来后发现自己身处于一片破损的木质海筏上。你希望找到圣地亚诺城失落的真相。

## 一、无边海洋

主世界被无尽海域吞没，没有大陆，只有遗迹与残骸。传送魔法在这里失效，必须建造“传送核心”才能前往下界与末地。

- 初始氧气为 **45 秒**，下水前必须规划呼吸与返程。
- 海底深度在 **50–300 格**，不同深度对应不同资源与风险。
- 出生点是漂浮残地，玩家从这里向海面扩展城市。
- 玩家在钓鱼和深潜探索遗迹的时候会找到建筑设计图纸（用于“复兴建筑”）。

### 海底呼吸

深海不是死路，海底分布着多种可供呼吸的机制：

- 气泡：可补充氧气的气泡区域。
- 海底热泉：持续提供空气的水下烟囱/热泉。
- 富氧区：氧气浓度更高的特殊水域。

## 二、深海压力

随着下潜深度增加，深海环境会带来更高风险。越深的地方资源越好，但也越需要玩家准备装备、规划氧气、判断是否值得冒险。深海是圣蒂亚诺危险与回报并存的核心地带。

## 三、更强原版生物

原版怪物不再只是经验与掉落物。

- 怪物会更快、更强、更聪明。
- 怪物会随机获得新的行为与技能，每次遭遇都可能不同。
- 有时会出现强大的精英怪，需要团队或充分准备才能应对。

配合深海环境与压力系统，夜晚和深海的威胁会明显高于原版。

## 四、营火增强

营火从装饰品变成真正的生存据点。

- 提供生命恢复。
- 解锁额外营火配方。
- 加速烹饪速度。
- 对附近怪物施加减益。
- 自动熄灭与火焰时长管理，避免营火被无限滥用。

## 五、墓碑

玩家死亡后会在死亡位置生成墓碑，保护掉落物品，最长一小时。

## 六、社交与趣味

- 拴绳可以拴玩家：用拴绳直接牵着队友走，方便救援、带路与搬运。
- 空手右键可骑在玩家身上：还可以坐下、趴下，适合合影、摆摊与日常互动。
- 手持望远镜发光：手持望远镜时，目标会被高亮标记，远海导航与观察更直观。

## 七、钓鱼扩展

钓鱼是圣蒂亚诺经济与探索的重要一环。

- 不同群系、深度、天气会钓到不同鱼类。
- 鱼可以卖给商店换取金币。
- 定期举办钓鱼大赛，排名靠前可获得钻石与经验奖励。
- 与无边海洋、复兴建设、施工图纸等玩法互相衔接。

默认原版钓鱼，使用 `/emf toggle` 切换为扩展钓鱼（金币鱼）。不同群系、不同深度钓出的鱼不一样。长度越长、稀有度越高的鱼价值越高。每天有钓鱼大赛，周末和周日的钓鱼大赛奖励最丰厚。

## 八、末地与下界拓展

两个维度不再是原版默认内容，而是随世界进度逐步开放。

- **下界拓展**：紫晶下界带来全新生态、结构与内容。资料见 [Amethyst Nether](https://modrinth.com/datapack/amethyst-nether)。
- **末地拓展**：Stellarity 对末地进行大型扩展。资料见 [Stellarity](https://prismaticshards.wiki.gg/wiki/Stellarity)。部分末地群系可以虚空钓鱼。
- **如何传送**：需要建设复兴建筑：传送核心，或在拓荒者主城设计并建设传送核心。

维度内容与主世界的海洋生存、复兴建设共同构成圣蒂亚诺的完整循环。

## 九、玩家成长

多条成长路线并行推进，路线之间互不冲突。

- 战斗、生存、建造、探索等方向可以同步成长。
- 你可以主攻深海探索，同时参与复兴建设，不必为了一个路线放弃另一个。
- 怪物也会随服务器进程同步增强，部分怪物会佩戴被其击败玩家的头颅，成为服务器历史的一部分。

## 十、身份与头衔

你可以自由选择成为 **筑城者**、**复兴者**、**拓荒者** 或 **自由人**，每条路线互不冲突。

### 自由人

- 所有玩家初始身份均为自由人。
- 自由人可以参与“复兴建筑”计划，推进公共建设进度。

### 复兴者

- 参与“复兴建筑”计划，推进进度累计达到 100%，即可获得头衔复兴者。
- 复兴者依然可以帮助其他公会进行建设，头衔并不限制玩家继续贡献。

### 拓荒者与公会

- 建立公会需要拥有自己的主城与城名，主城至少需要 **100×100 的陆地** 与 **10,000 金币**。
- 公会人数至少 2 人。
- 加入任意公会即显示拓荒者头衔。
- 拓荒者依然可以参与复兴建设。
- 公会需要编写自己的故事，并自行编写建筑增益；通过审核后，这些建筑增益会获得实际效果。

### 筑城者

- 筑城者需要申请，审核通过后可前往创造服设计“复兴建筑”。
- 复兴建筑在生存服中只需极少的材料即可由复兴者推进进度。
- 例如：某建筑原材料需要数十种不同材料，但每名玩家推进建筑进度只需 **100 木、100 石、100 金**。

## 十一、复兴建设

公共建筑按五个阶段推进，每阶段累计 100% 才进入下一阶段。

- 每名玩家对单个阶段的贡献上限为 10%，潮汐水晶可额外推进 10% 至 20%，防止单人垄断。
- 下一阶段需要完成指定远征事件后解锁。
- 建筑完成后会解锁持续的世界功能，并触发全服广播。

城市阶段：

```text
0 残礁遗迹 → 1 旧貌初现 → 2 初有人烟 → 3 渐有生气 → 4 焕然一新 → 5 圣地亚诺
```

## 十二、海雾远征

- 完成“复兴建筑”可能会出现“海雾事件”。
- 事件包括被困的游荡村民、水下邪恶地牢、沉船商队、下界裂缝等。
- 玩家共同选择会影响后续故事走向。
- 选择会累积为三种倾向：守望、燃潮、断潮。
- 三种倾向决定圣蒂亚诺的方向。
