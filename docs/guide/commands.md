# 指令手册

本页整理普通玩家可使用的常用指令。尖括号中的内容需要替换，例如 `<玩家>` 应填写实际玩家名。

## 经济与商店

| 指令 | 用途 |
| --- | --- |
| `/money` | 查看经济系统帮助 |
| `/shop` | 打开服务器商店 |
| `/shop deepblue` | 打开深蓝钓鱼交易市场 |

## 钓鱼系统

| 指令 | 用途 |
| --- | --- |
| `/emf` | 打开 EvenMoreFish 主界面 |
| `/emf top` | 查看钓鱼排行榜 |
| `/emf next` | 查看下一场钓鱼比赛 |
| `/emf toggle` | 切换原版钓鱼与 EvenMoreFish 钓鱼 |
| `/emf applybaits` | 将鱼饵应用到鱼竿 |
| `/deepbluefish area` | 查看当前深蓝钓鱼区域 |

## DirectionHUD 导航

| 指令 | 用途 |
| --- | --- |
| `/hud` | 设置或切换方向 HUD |
| `/destination` | 管理目标地点 |
| `/destination set <坐标>` | 设置目标地点 |
| `/destination clear` | 清除当前目标 |
| `/destination save` | 保存个人地点 |
| `/destination track <玩家>` | 追踪玩家 |
| `/directionhud` | 打开插件主菜单 |

`/destination` 可简写为 `/dest`，`/directionhud` 可简写为 `/dhud`。

## 动作指令

| 指令 | 用途 |
| --- | --- |
| `/sit` | 坐下，也可直接右键楼梯或台阶 |
| `/sit toggle` | 切换点击坐下 |
| `/sit playertoggle` | 切换是否允许坐在其他玩家身上 |
| `/lay` | 躺下 |
| `/layback` | 仰躺 |
| `/bellyflop` | 趴下 |
| `/spin` | 使用旋转姿势 |
| `/crawl` | 爬行 |
| `/crawl toggle` | 切换潜行触发爬行 |

对应的完整命令还有 `/gsit`、`/glay`、`/glayback`、`/gbellyflop`、`/gspin` 和 `/gcrawl`。

## 皮肤

| 指令 | 用途 |
| --- | --- |
| `/skin` | 查看皮肤指令帮助 |
| `/skin set <玩家名>` | 使用指定正版玩家的皮肤 |
| `/skin set <皮肤链接>` | 使用链接中的皮肤 |
| `/skin clear` | 清除当前设置的皮肤 |
| `/skin update` | 刷新当前皮肤 |
| `/skin undo` | 撤销最近一次皮肤更改 |
| `/skin history` | 查看皮肤历史 |
| `/skin favourite` | 管理收藏皮肤 |
| `/skins` | 打开皮肤选择界面 |

普通玩家拥有默认换肤权限，换肤冷却时间为 **30 秒**。

## 登录与账号

以下指令主要用于非正版玩家：

| 指令 | 用途 |
| --- | --- |
| `/register <密码> <确认密码>` | 注册账号，可简写为 `/reg` |
| `/login <密码>` | 登录账号，可简写为 `/l` |
| `/logout` | 退出登录状态 |
| `/disconnect` | 主动断开服务器连接 |
| `/changepassword <旧密码> <新密码>` | 修改密码 |
| `/unregister <密码>` | 删除自己的服务器账号 |
| `/captcha <验证码>` | 完成验证码 |
| `/email ...` | 管理恢复邮箱 |
| `/2fa ...` | 管理双重验证 |

::: warning 账号安全
请为服务器设置独立密码，不要使用 QQ、邮箱、启动器或其他网站的密码。管理员不会向你索要密码。
:::

## 墓碑

| 指令 | 用途 |
| --- | --- |
| `/grave list` | 查看自己的墓碑 |

普通玩家不能查看其他玩家的墓碑。死亡后墓碑仅保留 **1 小时**。

## 奖励与状态

| 指令 | 用途 |
| --- | --- |
| `/rewards` | 打开待领取奖励 |

> 指令可能随服务器更新调整，请以最新公告为准。
