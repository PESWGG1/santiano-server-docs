# 指令手册

这里整理玩家常用指令，多数指令输入 /help 也能查看。

## 一、基础指令

| 指令 | 说明 |
| --- | --- |
| /help | 查看帮助 |
| /spawn | 回到出生点 |
| /home | 传送回家 |
| /sethome | 设置家 |
| /tpa 玩家名 | 请求传送到某玩家 |
| /tpaccept | 接受传送请求 |
| /msg 玩家名 内容 | 私聊玩家 |
| /list | 查看在线玩家 |

## 二、领地与传送

待补充：根据服务器安装的领地 / 传送插件填写。

## 三、经济指令

待补充：根据经济插件填写，例如商店、交易、货币查询。

仅管理员可用，待补充权限说明。
