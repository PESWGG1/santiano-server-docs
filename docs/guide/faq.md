# 常见问题

## 1. 无法连接服务器 / 无法解析主机名

- Santiano 采用审核制，服务器地址不公开。请确认你已经通过审核，并使用管理员提供的地址。
- 检查服务器地址是否完整、填写正确，不要从非官方渠道获取地址。
- 确认网络正常，尝试重启游戏或路由器。
- 查看群公告，确认服务器是否在维护。

## 2. 提示版本不匹配

- 将游戏切换为 Minecraft Java 版 26.2。

## 3. 进入后很卡 / 延迟高

- 检查网络与电脑配置。
- 关闭后台占用较大的程序。
- 尝试降低画面设置。

## 4. 物品丢失 / 出现回档

- 死亡会生成保留 1 小时的墓碑，可使用 `/grave list` 查看自己的墓碑。
- 如果不是正常死亡掉落，或怀疑出现回档，请联系管理员并提供时间、地点、物品和相关截图。

## 5. 登录失败 / 账号相关

- 服务器不要求正版账号。
- 首次进入请使用 `/register <密码> <确认密码>` 注册，之后使用 `/login <密码>` 登录。
- 请确认玩家名称和启动器设置正常，并保持玩家名称稳定。
- 忘记密码时可尝试已配置的恢复邮箱；无法恢复时联系管理员。
- 仍无法登录时，在审核群联系管理员并附上完整报错截图。

## 6. 可以使用哪些客户端模组？

- 推荐使用纯原版客户端。
- 小地图不得开启生物雷达和洞穴模式。
- 投影只允许用于自己的原创建筑，禁止使用投影打印机。
- 禁止灵魂出窍等明显影响公平性的强力功能。
- 不确定时，请先在审核群询问管理员。

## 7. 需要安装模组或资源包吗？

不需要。使用纯原版 Minecraft Java 版 26.2 客户端即可进入服务器。

## 8. 如何申请入服？

加入审核 QQ 群 **1070493995**，按照群内要求完成审核。审核通过后，管理员会提供服务器地址。

## 9. 可以 PVP、拿别人东西或拆建筑吗？

不可以。Santiano 是合作服务器，禁止 PVP、偷窃和破坏他人成果。完整要求请阅读「游玩规则」。

## 10. 地图会重置吗？

地图不会定期重置，服务器鼓励长期建设与共同发展。

## 还没解决？

在审核 QQ 群 **1070493995** 联系管理员，并附上截图、发生时间和问题描述。处罚申诉也在群内提交。
