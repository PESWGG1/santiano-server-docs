# 常见问题

## 1. 无法连接服务器 / 无法解析主机名

- 检查服务器地址是否填写正确。
- 确认网络正常，尝试重启游戏或路由器。
- 查看群公告，确认服务器是否在维护。

## 2. 提示版本不匹配

- 将游戏版本切换为服务器要求的版本。

## 3. 进入后很卡 / 延迟高

- 检查网络与电脑配置。
- 关闭后台占用较大的程序。
- 尝试降低画面设置。

## 4. 物品丢失 / 出现回档

- 联系管理员，并尽量提供时间、地点等线索。

## 5. 登录失败 / 账号相关

- 待补充：根据服务器的登录方式说明。

## 还没解决？

在交流群联系管理员，并附上截图和问题描述。
